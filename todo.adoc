== Todo
While the base features of Espirit are done, there's still some features that
Espirit could get to improve its experience. Below is (fairly loose) planning
on what next versions of the library may get.

=== Features
* MVP
** [x] Recognition of record deletion
** [ ] Allow subrecords to be read in any order (compatibility matters)
** [ ] Improve performance, especially on bigger files
*** [ ] Make parsing through multiple processes (e.g. process pool)
* High priority, but not required
** [ ] Allow `AND` on plugins to produce new plugin (comparable to merge)
** [ ] Export/serialize .esm/.esp (e.g. after changes)
** [ ] Convert between .esm/.esp
** [ ] JSONify plugin data
* Nice-to-have
** [ ] Make all records/subrecords have their length included
** [ ] Abstract the records even more, so the code can be cleaner and more modular
